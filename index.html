① 第一次使用：60 秒完成第一張圖
  1. 首頁按 「編輯內容」。
  2. 直接點「核心命題」、三個區塊標題、內文或下方標籤，改成自己的內容。
  3. 回首頁或底部按 「風格」，選一種喜歡的樣式。
  4. 按 「輸出」，確認預覽，再選「高清 PNG」或「列印／PDF」。
不需要另外按儲存：停止輸入約 0.35 秒後會自動保存。
② 如何修改文字、增加區塊與標籤？
  • 修改：直接點任何可編輯文字後輸入。
  • 新增主要區塊：到「編輯內容」頁按「＋ 新增區塊」。最多 6 個。
  • 刪除區塊：區塊右上角按「×」。至少保留 1 個區塊。
  • 新增標籤：按「＋ 新增標籤」，新標籤會出現在邏輯圖下方。
  • 刪除標籤：把該標籤文字全部刪空，再點到其他地方，系統會自動移除空標籤。
若想快速測試，可按「🪄 載入示範」。
③ 7 種風格怎麼選？
  • 禪風：知識整理、人生觀、身心主題。
  • 水墨：古文、東方哲學、文化內容。
  • 昭和：復古宣傳、歷史回顧、懷舊主題。
  • 黏土：親子、長輩、衛教、友善教學。
  • 貼紙：社群、簡單分享、可愛圖卡。
  • 巴洛克：正式、高端、品牌提案。
  • 科技：AI、工程、流程、系統架構。
切換風格只會改外觀，不會改掉你已輸入的內容。
④ 如何輸出 PNG 圖片？
  1. 進入「輸出」頁。
  2. 確認「輸出前檢查」沒有明顯缺漏。
  3. 按 「匯出高清 PNG」。
  4. 瀏覽器會自動建立 2 倍解析度圖片並下載。
PNG 依賴網路載入 html2canvas。若首次開啟時沒有網路，請連網後重新整理。
⑤ 如何存成 PDF 或列印？
  1. 進入「輸出」頁，按 「列印／另存 PDF」。
  2. 電腦 Chrome：目的地選「另存為 PDF」。
  3. Android：列印畫面通常可選「儲存為 PDF」。
  4. 若背景圖案沒有顯示，請在列印設定開啟「背景圖形／背景顏色」。
⑥ JSON 備份與還原是做什麼？
  • 匯出 JSON：把目前作品保存成可還原的設定檔。
  • 匯入 JSON：換瀏覽器或換裝置後，把設定檔重新載回。
  • 本版會檢查版本、節點數量與內容型態，並清除危險 HTML 屬性。
JSON 是「作品備份」，PNG/PDF 是「成品輸出」，用途不同。
⑦ 明暗模式與字體大小
  • 右上角 ◐：依序切換「跟隨系統 → 明亮 → 深色」。
  • 右上角 A：依序切換「標準 → 大字 → 特大字」。
  • 設定會自動保存在目前瀏覽器。
明暗模式只調整操作介面；作品的 7 種輸出風格仍維持原本設計。
⑧ 常見問題排除
  • PNG 沒反應：確認網路，重新整理後再試。
  • 匯入 JSON 失敗：確認檔案是由本工具匯出，且沒有被文字編輯器破壞格式。
  • 文字跑版：縮短單一標籤文字，或減少主要區塊數量。
  • 手機畫面太小：按右上 A 切回標準字體，輸出 PNG 時仍會用固定 820px 畫布生成高清圖。
  • 想完全重來：到「資料管理」→「清空並恢復預設」。
